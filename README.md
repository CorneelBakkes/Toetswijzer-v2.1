# Toetswijzer Pabo Sittard

De Toetswijzer toont studenten de toetsafnames, intekenperioden, inleverperioden en beoordelingsmomenten voor hun opleidingsvariant.

## Website

https://corneelbakkes.github.io/Toetswijzer-v2.1/

## Planning bijwerken

`Toetswijzer-invulbladen.xlsx` is de enige gegevensbron voor de planning. Werk **Momenten**, **Weekstructuur**, **Toets-EvL** en **Links** bij en vervang daarna het bestand op GitHub met exact dezelfde bestandsnaam. De website leest het bestand bij het openen opnieuw in.

Pas `index.html` alleen aan voor wijzigingen aan de website zelf.

## Bestanden

- `index.html` — de gepubliceerde website;
- `Toetswijzer-invulbladen.xlsx` — planning, doelgroepen, weekindeling, toets–EvL-koppelingen en links;
- `Handleiding.html` — korte uitleg voor het beheren van het Excelbestand.
